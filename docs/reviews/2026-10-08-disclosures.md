The GDC limitation is layered and reproducible:

- All five terminal labels use a `PRE` with `style="text-align: right;"`. The existing contract excludes **every attribute on evidence**, even a style that appears innocuous.
- All five RSS bodies append a linked publisher-attribution paragraph after the label. Links are unsupported following content, so this independently fails the tail guard. Campoli also has an empty classed paragraph after the copyright line.
- Three bodies (both Oceanya articles and the Antica Scuderia dinner) contain a gallery `STYLE` element. This triggers the earlier whole-fragment active-content veto, which can conceal the other two reasons.

Removing active nodes in a temporary diagnostic copy changes those three holds to `unsupported-disclosure-context`. Removing the PRE style next changes all five holds to `unsafe-disclosure-tail`. These diagnostic copies were never used as publication evidence. The four active-content Colli holds also lack approved disclosure labels; active markup is not an advertising signal.

The PR reports these distinct conditions without changing the block predicate, limits, vocabulary, cutoff, conflict handling, or publication gates. Reasons identify one encountered blocker, not every blocker. `no-supported-disclosure` does not mean verified non-advertising. Worker failures, parser failures, and resource limits stay review-only.

Do **not** globally strip styles, discard all material after a label, permit arbitrary PRE attributes, remove the active-content veto, or classify by brand/event words. Any future GDC adapter would need separately reviewed, narrow source-boundary rules and adversarial tests for forged attribution footers, wrong canonical links, hidden labels, later editorial material and active gallery stylesheets. Those policy extensions are not implemented here.
